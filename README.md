# PixelQuest 🎮

Un jeu d'aventure 2D en cours de développement par une équipe de passionnés.

## Description
PixelQuest est un jeu de plateformes en Python où le joueur explore des donjons,
affronte des ennemis et tente de survivre le plus longtemps possible.

## Lancer le jeu
```bash
python main.py
```
